# CENSUS: code paths in this repository that can read the position-0 state

Fathom Lab, 2026-11-10. One lab, one machine, read only: no model or tokenizer was loaded for this census and no
existing file was edited. Four readers each took one part of the repository and a fifth pass tried to refute them.
All five are the lab's own; there has been no outside review. Outside reruns: 0.

This census follows `papers/real-convergence/ERRATUM_real_convergence_2026_11_10.md`. Read the erratum before this
file. This census does not say whether any published result is wrong or right. It lists where the code can put
the position-0 state into a number, and which documents report numbers from that code.

## what was asked

The erratum found that the lab's June pipeline read the last token of 8 templates, template 0 being the bare word
`"{w}"`. The tokenizers of Qwen2.5, Phi-3.5, GPT-2 and Pythia add no start token, so a word that is one token sat
alone at position 0. Qwen2.5 and Phi-3.5 carry a very large activation there (measured in the erratum; described
by Sun, Chen, Kolter, Liu, arXiv 2402.17762); for GPT-2 and Pythia the lab has not measured it.
The question for every other script: can a hidden-state read in it land on the position-0 state, or include it?

Classes used:

- **E1**: a read at the last position of an input that can be one token with no start token, so the read is the
  position-0 state. "E1 inherited" marks a script that runs no model and computes from stored arrays written by an
  E1 site.
- **E2**: a mean or sum over positions that include position 0.
- **E3**: position 0 read directly, alone or as one row of a whole-sequence trajectory.
- **U**: cannot tell from the repository.
- **N**: not exposed. Called "cleared" below.

## how the files were listed

Each reader ran, over its part of the tracked files:

```
git grep -l -E "output_hidden_states|hidden_states\[|register_forward_hook|run_with_cache|resid_post|resid_pre" -- "*.py"
```

`papers/real-convergence/run_real_convergence_v2.py` lines 54-62), through `.last_hidden_state`, or through

## the method's limits

- It reads code paths. It measures no number. A site classed E1 shows that the position-0 state can enter a number;
  how much it moves that number is a separate measurement. The erratum made it for the June helper at layer
  max(1, int(0.66 L)) on its sealed models; for the sites of this census it was not made.
- A cleared site can still carry another artifact. Every read after position 0 can attend to position 0; this
  census asks only whether the read itself is, or averages in, the position-0 state. The erratum's other limits (a
  frame such as "a" before the word, shared by every model) apply to cleared sites too.
- The pattern misses reads through helpers, untracked modules and library wrappers. The readers added what they
  found by a second search; the refutation pass found more (below).
- Which tokenizers add a start token comes from the erratum (Qwen2.5, Phi-3.5, GPT-2 and Pythia add none;
  Llama-3.2 adds one) and from the lab's reading of cached tokenizer configuration files, which are not in the
  repository (DistilGPT-2, BLOOM-560m and Mamba-1.4b add none; bert-base-uncased and all-MiniLM-L6-v2 put `[CLS]`
  at position 0 and all-mpnet-base-v2 puts `<s>` there). Whether gemma-2-2b-it adds one is not shown by any file on
  the lab's machine: it is no longer in the cache.
- TransformerLens and circuit-tracer behaviour (both prepend a start token by default) was read from the installed
  versions, TransformerLens 2.17.0 and a local circuit-tracer clone. Other versions were not checked.
